# DigitalHut Current Plan

DigitalHut.app is a platform that handles library storage, backend asset operations, and an AI presentation system.

## Core Platform

- Website / DApp
- Backend and AI system
- Library storage
- Search and category routing
- GLB renderer
- Account system
- Wallet connection
- Standard, Premium, and Pro tiers

## Backend System

- Upload queue
- Original source file storage
- Converted GLB storage
- Profile GLB library
- File records
- Comments
- Likes
- Shares
- Sponsor attachment lane
- Metadata and description editing

## Conversion System

- Accept source files such as GLB, GLTF, OBJ, FBX, STL, BLEND, image sets, scans, and research sources
- Store the original file in Supabase Storage
- Dispatch the conversion job to the worker service
- Convert the source into GLB
- Compress and optimize the GLB
- Generate thumbnail and metadata
- Generate AI spoken dialogue
- Mark the queue item complete only when the AI narration is ready

## AI System

The public AI system presents one current model:

- opens the model
- rotates the model
- zooms in and out by stage
- explains details
- pauses for the user
- saves profile/library records

The protected future demo system stays private until the community is ready:

- 360 recommendation intelligence
- related GLB shuffle
- deeper live camera choreography
- multi-model presentations
- creator-controlled demo editing
- advanced sponsor and contest presentation flows

Unlock target: 10,000 subscribers.

## API Lanes

DigitalHut can connect category-specific providers over time:

- real estate and property APIs
- gaming / 3D asset APIs
- education and research sources
- maps and location sources
- market intelligence
- mainstream and creator feeds
- SEO and profile discovery data

## Product Direction

The platform should feel like a full-screen operating system, not a normal upload page. The backend is a private control center. The public app is a streamlined AI-guided GLB presentation feed that grows through community comments, likes, shares, questions, sponsors, and saved model libraries.
