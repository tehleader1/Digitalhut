# DigitalHut Current Plan

DigitalHut.app is a platform that handles library storage, backend asset operations, and an AI presentation system.

## Core Platform

- Website / DApp
- Backend and AI system
- Library storage
- Search and category routing
- GLB renderer
- Account system
- Wallet connection
- Standard, Premium, and Pro tiers

## Final Working Product Backend Blueprint

DigitalHut has two major visible lanes:

- Public main screen: the streamlined 3D observatory where users search, open models, watch the AI present one current model, save, share, and explore.
- Private backend: the control room where Anthony manages uploads, reports, queues, profiles, comments, files, GLBs, sponsors, and the protected AI demo features.

The backend should feel like a full-screen sit-down system, not a small settings panel.

## Private Backend

- Asset scene sit-down workspace
- Edit current/public asset records
- Source file and converted GLB comparison
- Upload and queue management
- Profiles, comments, likes, shares, and files
- Sponsor attachment lane
- Backend archive
- Daily Situation Discovery backend
- Protected AI control demo features

## Stack

- Free/local/sustainable backend first
- Website / DApp
- Wallet connection
- Account system
- APIs
- Supabase for storage/database
- Physical asset support: FireCuda, Android, HP Mini Laptop
- Search engine and category intelligence
- Premium and Pro access controls

## Backend System

- Upload queue
- Original source file storage
- Converted GLB storage
- Profile GLB library
- File records
- Comments
- Likes
- Shares
- Sponsor attachment lane
- Metadata and description editing
- Backend records for Africa/continent GLBs and other location files
- Public/private visibility controls

## Backend Queue

The backend queue handles:

- profiles
- comments
- files
- connector/API records
- uploaded GLBs
- converted GLBs
- report candidates
- daily discovery candidates
- published report archive

Every queue item should show:

- status
- source
- file type
- confidence or readiness
- related GLB/asset match
- comments and review notes
- publish state

## Conversion System

- Accept source files such as GLB, GLTF, OBJ, FBX, STL, BLEND, image sets, scans, and research sources
- Store the original file in Supabase Storage
- Dispatch the conversion job to the worker service
- Convert the source into GLB
- Compress and optimize the GLB
- Generate thumbnail and metadata
- Generate AI spoken dialogue
- Mark the queue item complete only when the AI narration is ready

## AI System

The public AI system presents one current model:

- opens the model
- rotates the model
- zooms in and out by stage
- explains details
- pauses for the user
- saves profile/library records

The private AI system controls protected demo intelligence:

- 360 recommendation system
- related model choice
- richer camera direction
- scene sequencing
- protected rotate / zoom / shuffle
- private creator testing

The protected future demo system stays private until the community is ready:

- 360 recommendation intelligence
- related GLB shuffle
- deeper live camera choreography
- multi-model presentations
- creator-controlled demo editing
- advanced sponsor and contest presentation flows

Unlock target: 10,000 subscribers.

## API Lanes

DigitalHut can connect category-specific providers over time:

- real estate and property APIs
- gaming / 3D asset APIs
- education and research sources
- maps and location sources
- market intelligence
- mainstream and creator feeds
- SEO and profile discovery data

## Product Direction

The platform should feel like a full-screen operating system, not a normal upload page. The backend is a private control center. The public app is a streamlined AI-guided GLB presentation feed that grows through community comments, likes, shares, questions, sponsors, and saved model libraries.
