## Competitor Reference Points

### Sketchfab

Observed lane:

- 3D model publishing, sharing, embedding, viewing, and marketplace behavior.
- Strong baseline: real-time 3D interaction in browser instead of static screenshots.
- WebGL/WebXR viewer and public discovery are core advantages.

DigitalHut difference to test:

- DigitalHut should not only display a model.
- DigitalHut should connect thumbnail, blog, AI explanation, autoplay, category context, and GLB preview into a guided observatory experience.

### Thangs / 3D Search Platforms

Observed lane:

- Search, discovery, and model matching are major value points.
- Users want to find relevant 3D files fast.

DigitalHut difference to test:

- DigitalHut should attach models to situations, blogs, visual thumbnails, and guided presentations instead of only search result lists.

### Google Images

Observed lane:

- Image search depends on meaningful image context: filename, alt text, page text, captions, and relevance.

DigitalHut difference to test:

- DigitalHut thumbnails should become search surfaces.
- Each thumbnail should point into a live 3D render path, not a dead card.

5. Pixel records the action.

If any step is missing, the page is not a finished DigitalHut SEO/render asset.
