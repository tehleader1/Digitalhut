## Operating Order

1. Build the SEO foundation from long-tail keywords and general search phrases.
   - Goal: give DigitalHut original search roots before chasing narrow trend traffic.
   - Focus terms: 3D experience, 3D images, 3D environments, 3D presentation, real world visualization, AI guided 3D presentation, 3D observatory dapp, GLB renderer, home observatory, family observatory, premium observatory.

2. Register off-tier markets.
   - Markets: China, Europe, Middle East, Africa, Latin America, South Asia, island tourism lanes, research/education lanes, family travel lanes.
   - Purpose: avoid only competing in saturated United States startup/search lanes.
   - Output: keyword clusters by region, blog angles by region, thumbnail naming by region.

3. Make the visual path real.
   - DigitalHut thumbnail images are SEO assets, not decoration.
   - Each thumbnail should have:
     - descriptive file name
     - useful alt text
     - caption near the image
     - blog context
     - category context
     - click path into the live 3D render
   - Goal: thumbnail image ranks in Google Images, then routes the visitor into the DigitalHut 3D renderer.
   - Rule: no dead card loop. Thumbnail to real 3D preview must be obvious.

4. Produce one full week of blogs at these settings.
   - One focused blog cluster per day.
   - Each blog needs:
     - primary long-tail keyword
     - supporting keywords
     - DigitalHut thumbnail target
     - linked 3D render or GLB preview
     - internal backlink to category or asset page
     - pixel tracking goal
   - Do not mass-publish filler. Publish from real assets, real screenshots, real GLBs, or real DigitalHut workflow evidence.

5. Backtest results.
   - Compare:
     - backlinks
     - blog reads
     - GLB plays
     - Google Images behavior
     - search terms
     - category movement
     - wallet/tier/node clicks
   - Use instant, 6-hour, 12-hour, 24-hour, and 7-day windows.

6. Map FireCuda as the growth archive.
   - FireCuda folders should preserve:
     - original captures
     - optimized GLBs
     - thumbnails
     - SEO evidence
     - blog history
     - backlink notes
     - failed renders
     - winning assets
   - FireCuda is the evidence room for the next SEO/content cycle.

7. Rinse and repeat.
   - Tighten keywords from real behavior.
   - Improve thumbnails.
   - Improve GLB preview path.
   - Publish stronger blogs.
   - Archive evidence.
   - Repeat with better assets.
